# Авиабилеты — демонстрационный сайт

Лёгкий сайт из одного файла `index.html`, без установки зависимостей, сервера и регистрации.

- Главная с анимированным самолётом и популярными направлениями.
- Поиск рейсов с учебными результатами.
- Мои билеты: демонстрационные бронирования в локальном хранилище браузера.
- Мои данные: заполнение полей с локальным сохранением.

> Это учебный проект. Цены и рейсы вымышленные. Реального бронирования и платежей нет.

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

1. Создайте **публичный** репозиторий на https://github.com/new (например, `aviabilety-demo`).
2. Загрузите `index.html` в корень основной ветки `main` и сделайте commit.
3. Зайдите в **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
5. После завершения публикации откройте URL, который появится в разделе **Pages**.

Файл `index.html` самодостаточный: фотографии и оформление встроены в HTML.
