# Авиабилеты

Учебный сайт на HTML, CSS и JavaScript: поиск рейсов, оформление билетов и профиль пассажира.

[Открыть сайт](https://y26216048-design.github.io/seit/)

Для оформления билета нужно заполнить и сохранить профиль. Регистрация и билеты хранятся локально в браузере; серверной авторизации, реальной оплаты и бронирования нет.

## Запуск

```bash
python3 -m http.server 8765
```

Адрес: http://localhost:8765. Основной код — `index.html`, изображения и значки — в `assets/`.
