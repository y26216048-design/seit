# Авиабилеты

Статический сайт: поиск рейсов, профиль пассажира и список билетов.

- «Выбрать» открывает оформление; «Купить» сохраняет демонстрационный билет и переводит в «Мои билеты».
- ФИО, дата рождения, телефон и почта сохраняются кнопкой «Сохранить данные» и подставляются при оформлении.
- Билеты и профиль хранятся в localStorage текущего браузера. При первом посещении данные пустые.
- В профиле доступны личные данные и кнопка сохранения внизу; в билетах — единый список.
- Календарь даты вылета поддерживает повторное открытие и переключение месяцев.

Это демонстрационное оформление без списания денег, реальной брони и серверной авторизации. Данные не синхронизируются между устройствами.

## Запуск

Запустите из корня `python3 -m http.server 8765` и откройте `http://localhost:8765`.

GitHub Pages публикует корень ветки main. Папка assets нужна для изображений и значков.
