# Авиабилеты

Учебный сайт для поиска авиарейсов и демонстрационного оформления билетов. Три раздела переключаются в верхнем меню без перезагрузки страницы.

**Сайт:** https://y26216048-design.github.io/seit/

## Разделы сайта

### Поиск рейсов

Пользователь выбирает город отправления, город прибытия, дату вылета и количество пассажиров. Нажатие на любую часть поля открывает выбор. Кнопка со встречными стрелками между городами меняет их местами.

Календарь позволяет выбирать день и переключать месяцы. Он открывается повторно при каждом нажатии. Кнопка «Найти рейсы» применяет выбранный маршрут к демонстрационным результатам. Фильтры слева ограничивают результаты по авиакомпании и количеству пересадок. Все имеющиеся демонстрационные рейсы прямые, поэтому при выборе одной пересадки список пуст.

Кнопка «Выбрать» открывает оформление выбранного рейса. Пользователь указывает ФИО и нажимает «Купить». Стоимость рассчитывается с учётом количества пассажиров. После оформления сайт открывает раздел «Мои билеты».

### Мои билеты

Единый список оформленных билетов. В каждом билете показаны авиакомпания, номер рейса и заказа, маршрут, время отправления и прибытия, длительность перелёта, дата, ФИО пассажира, количество пассажиров и стоимость.

До первой покупки список пуст. Оформленные билеты остаются после перезагрузки страницы.

### Мой профиль

Форма содержит ФИО, дату рождения, телефон и электронную почту. Кнопка «Сохранить данные» под полями проверяет заполнение и сохраняет профиль. При успешном сохранении появляется короткое подтверждение.

ФИО из профиля автоматически подставляется при следующем оформлении билета. При первом посещении поля пустые.

## Как проверить работу

1. Открыть «Мой профиль», заполнить четыре поля и сохранить данные.
2. Перейти в «Поиск рейсов», выбрать города нажатием на поля и проверить обмен городов кнопкой между ними.
3. Открыть календарь, выбрать дату, затем открыть календарь ещё раз и изменить её.
4. Выбрать количество пассажиров и нажать «Найти рейсы».
5. Нажать «Выбрать» у рейса: ФИО должно подставиться из профиля.
6. Нажать «Купить»: в разделе «Мои билеты» появится оформленный билет.
7. Перезагрузить страницу и проверить, что профиль и билет сохранились.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка трёх разделов, стили, обработка кнопок, календарь, фильтры, оформление и сохранение данных. |
| `assets/sky.webp` | Фоновое изображение самолёта и гор. |
| `assets/plane-logo.webp` | Логотип сайта. |
| `assets/lucide.min.js` | Набор значков интерфейса. |

Используются HTML, CSS и JavaScript. Отдельный сервер приложения и установка зависимостей для запуска не нужны. Профиль и билеты хранятся в localStorage браузера. После очистки данных сайта они удаляются; на другом устройстве автоматически не появляются.

Рейсы и цены демонстрационные. Нажатие «Купить» создаёт учебный билет: деньги не списываются, реальная бронь у авиакомпании не создаётся. Входа с паролем и серверной авторизации нет. Для проверки используйте вымышленные персональные данные.

## Локальный запуск

Из папки проекта запустить:

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765. Сайт также опубликован через GitHub Pages из корня ветки `main`.
