# Авиабилеты

Учебный сайт для поиска рейсов и оформления билетов. Есть регистрация через профиль и сохранение данных в браузере. Оплата и реальное бронирование не подключены.

[Открыть сайт](https://y26216048-design.github.io/seit/)

HTML находится в `index.html`, стили — в `style.css`, JavaScript — в `script.js`.

Для запуска: `python3 -m http.server 8765`, затем открыть http://localhost:8765.
