# Авиабилеты

На сайте можно выбрать маршрут и дату вылета, оформить билет и посмотреть его в разделе «Мои билеты». В разделе «Мой профиль» можно заполнить, сохранить или удалить свои данные.

[Открыть сайт](https://y26216048-design.github.io/seit/)

## Файлы проекта

- **index.html** — страницы «Поиск рейсов», «Мои билеты» и «Мой профиль»: заголовки, поля, кнопки и карточки рейсов.
- **style.css** — оформление сайта: цвета, шрифты, размеры и расположение элементов на компьютере и телефоне.
- **script.js** — работа кнопок, выбор городов и даты, регистрация, оформление билетов и сохранение данных.
- **assets** — фоновая картинка и значки для интерфейса.
